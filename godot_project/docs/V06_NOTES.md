# Version 0.6 — additional artillery mechanics

Added three weapons (16 total): Splitterregen, Bohrer, Mega-Dirt. Splitterregen places a delayed line of shrapnel blasts over the terrain; Bohrer penetrates vertically through the heightmap with delayed blasts; Mega-Dirt raises a broad mound. Added bounded heightmap slope relaxation after crater deformation and the new large dirt mound.

This is an original interpretation, **not** verified parity with Scorched Earth 1.5. Existing weapons and defenses remain simplified. No Godot runtime or Android APK validation has been performed. Manual validation: import project, start a round, purchase each new weapon, fire against multiple terrain elevations, verify shot completion and CPU turns, verify shield/fall damage, test Android landscape scaling.
